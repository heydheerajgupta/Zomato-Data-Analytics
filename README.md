# 🍽️ Zomato Data Analytics Project

An end-to-end restaurant data analytics project using Excel, SQL, Power BI and Tableau.

## 🛠️ Tools & Technologies

- Microsoft Excel
- MySQL
- Power BI
- Tableau

## 📂 Project Modules

| Module | Tool | Details |
|---|---|---|
| Excel | Microsoft Excel | Data cleaning, modeling, analysis and dashboard |
| Power BI | Power BI | Data modeling, DAX and interactive dashboards |
| SQL | MySQL | SQL-based restaurant data analysis |
| Tableau | Tableau | Interactive data visualization and dashboard |

## 📊 Modules

- [Excel Analysis](./02_Excel/)
- [Power BI Analysis](./03_PowerBI/)
- [SQL Analysis](./04_SQL/)
- [Tableau Analysis](./05_Tableau/)

## 📁 Dataset

The project uses a Zomato restaurant dataset containing information related to restaurants, countries, cities, cuisines, ratings, pricing and service availability.
