# 📊 Zomato Data Analysis — Power BI

An interactive Power BI restaurant analytics project developed as part of an end-to-end Zomato Data Analytics project.

The project analyzes restaurant distribution, ratings, cuisines, locations, pricing, restaurant opening trends, table booking and online delivery availability.

## 🎯 Project Objective

The objective of this Power BI project is to transform Zomato restaurant data into an interactive business intelligence dashboard.

The analysis focuses on:

- Restaurant distribution across countries and cities
- Restaurant opening trends over time
- Restaurant ratings and rating categories
- Average cost for two
- Table booking availability
- Online delivery availability
- Popular cuisines
- Top cities by restaurant count
- India vs Global restaurant distribution

## 📈 Dashboard Visualizations

The Power BI dashboard includes the following visualizations:

### Restaurant Opening by Year

Shows the number of restaurants opened across different years and helps identify restaurant growth patterns over time.

### Restaurant Count by Country

Shows the geographical distribution of restaurants across countries.

### India vs Global Restaurant Distribution

Compares restaurant presence in India with the rest of the world.

### Global Restaurant Distribution

Analyzes restaurant distribution across countries outside India.

### Top 10 Cuisines

Identifies the most popular cuisines based on restaurant count.

### Online Delivery Availability

Shows the percentage of restaurants offering online delivery.

### Table Booking Availability

Shows the percentage of restaurants offering table booking facilities.

### Restaurant Rating Distribution

Analyzes restaurants across different rating categories:

- Average (1–2)
- Good (2–3)
- Very Good (3–4)
- Excellent (4–5)

### Top 5 Cities by Restaurant Count

Identifies the cities with the highest number of restaurants.

## 📋 Analysis Performed

### 1. Data Modeling

Created a structured Power BI data model using the available Zomato dataset and supporting tables.

### 2. Calendar Table

Created a calendar table based on restaurant opening dates.

The calendar analysis includes:

- Year
- Month Number
- Month Name
- Quarter
- Year-Month
- Weekday Number
- Weekday Name
- Financial Month
- Financial Quarter

### 3. Currency Conversion

Converted Average Cost for Two from local currencies into USD using the available currency information.

### 4. Restaurant Distribution

Analyzed restaurant counts across:

- Countries
- Cities
- India
- Rest of the World

### 5. Restaurant Opening Analysis

Analyzed restaurant openings by year to identify changes in restaurant growth over time.

### 6. Rating Analysis

Created rating categories and analyzed restaurant counts across different rating ranges.

### 7. Cuisine Analysis

Analyzed restaurant counts by cuisine and identified the most popular cuisines.

### 8. City Analysis

Identified the top cities based on restaurant count.

### 9. Table Booking Analysis

Analyzed the percentage of restaurants offering table booking facilities.

### 10. Online Delivery Analysis

Analyzed the percentage of restaurants offering online delivery.
