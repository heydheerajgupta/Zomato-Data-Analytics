# 📊 Zomato Data Analysis — Tableau

An interactive Tableau dashboard developed as part of an end-to-end Zomato Data Analytics project.

The project analyzes restaurant performance, ratings, cuisines, locations, pricing and service availability using Tableau.

---

## 🎯 Project Objective

The objective of this Tableau project is to transform Zomato restaurant data into an interactive and visually informative dashboard.

The analysis focuses on:

- Restaurant distribution by country and city
- Restaurant opening trends
- Restaurant ratings
- Average cost for two
- Restaurant pricing
- Popular cuisines
- Table booking availability
- Online delivery availability
- Geographic restaurant distribution

---

## 🛠️ Tool Used

**Tableau**

The project demonstrates practical use of:

- Data connection
- Data preparation
- Calculated fields
- Filters
- Parameters
- Interactive dashboards
- Charts and visualizations
- Geographic analysis

## 🔍 Key Analysis Areas

### 1. Restaurant Distribution

Analyzed restaurant distribution across different countries and cities to identify areas with a high concentration of restaurants.

### 2. Restaurant Opening Trends

Analyzed restaurant openings over time to understand growth patterns and changes in restaurant activity.

### 3. Rating Analysis

Analyzed restaurant ratings to understand the distribution of restaurant quality across the dataset.

### 4. Pricing Analysis

Analyzed the Average Cost for Two and price ranges to understand restaurant pricing patterns.

### 5. Cuisine Analysis

Identified popular cuisines based on restaurant count and distribution.

### 6. Table Booking

Analyzed the availability of table booking services across restaurants.

### 7. Online Delivery

Analyzed restaurants based on online delivery availability.
